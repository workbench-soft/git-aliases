# Как работать в репозитории

Когда изменение готово, агент MUST пройти три шага:

1. Агент MUST прогнать проверки, которые к нему относятся.
2. Агент MUST закоммитить файлы задачи. Чужие правки MUST NOT попасть в коммит.
3. Агент MUST запушить коммит в текущую удалённую ветку, не спрашивая.

Пользователь просит не коммитить или не пушить? Агент MUST сделать, как он сказал.
Проверка, коммит или пуш упали? Агент MUST назвать причину. Force push MUST NOT
идти без явного разрешения.
